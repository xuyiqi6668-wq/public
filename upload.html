Add a memory

Step 1 · Connect to GitHub

The site saves photos into your GitHub repository, so it needs an access key once on this device.

  1. Open GitHub → New fine-grained token.
  2. Name it e.g. baby diary. Under Repository access choose Only select repositories → .
  3. Under Permissions → Repository permissions, set Contents to Read and write.
  4. Click Generate token, copy it and paste it below.

The token stays only in this browser. Don't use this page on a shared computer.
